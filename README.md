## Description

This is a very simple example project built with the NestJS framework.

The purpose of this project is just to test and see in practice how an AI integration works.  
It is intentionally minimal and serves as a base for testing, and learning ai concepts.

This project is not production-ready.

---

## Environment Variables

Before running the project, you must create a:

.env.development

The `.env` file must follow this structure:

```env
DATABASE_URL="your_database_url" or get at: https://www.prisma.io/
APP_PORT=3000
GROQ_API_KEY="your_groq_api_key" get at: https://console.groq.com/home
